# Virtual International Infotech Portfolio

Official portfolio and showcase website for **Virtual International Infotech** (`virtualinternationalinfotech.com`).

Virtual International Infotech is a digital product studio operating 14+ online utilities for PDF processing, image editing, QR code/barcode generation, and financial calculators.

## Web Tools Network

1. [qrcodes-generators.com](https://qrcodes-generators.com) — QR code generation suite
2. [yourbarcodegenerator.com](https://yourbarcodegenerator.com) — Barcode generator
3. [gstcalculators.co.in](https://gstcalculators.co.in) — GST & tax calculators
4. [elevencalculator.com](https://elevencalculator.com) — Multi-purpose calculators
5. [pdfcompressed.de](https://pdfcompressed.de) — PDF compression (Europe/Germany)
6. [ilovepdftool.in](https://ilovepdftool.in) — All-in-one PDF utilities
7. [onlinepdfconverter.in](https://onlinepdfconverter.in) — Online PDF converter
8. [ilovedimg.com](https://ilovedimg.com) — Image optimization & conversion
9. [ilovedpdf.in](https://ilovedpdf.in) — PDF editing & processing
10. [pdfcompressed.com](https://pdfcompressed.com) — Global PDF compression
11. [freepdfmaker.in](https://freepdfmaker.in) — Free online PDF maker
12. [removebg.co.in](https://removebg.co.in) — Background removal tool
13. [iloveimgtool.com](https://iloveimgtool.com) — Image tools suite
14. [freepdf.co.in](https://freepdf.co.in) — Free online PDF utilities suite

## Tech Stack

- **Framework**: TanStack Start + React 19
- **Routing**: TanStack Router
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide Icons
- **Bundler**: Vite

## Getting Started

```sh
npm install
npm run dev
```

### Build for Production
